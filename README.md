# My Granddad was a Bugler — Year 3 Remembrance Day

Story © Robin McKean 2026. Six-page supplied family narrative retained. Historical context is separately labelled and sourced to Australian War Memorial pages. Personal narrative has not been independently checked against service records.

## Pages
- `index.html`: home, six-page story, historical context, sound and word help, activities, voluntary reflection, sources.
- `worksheet.html`: printable student worksheet, no solutions.
- `teacher/index.html`: separate 30–45 minute guide, differentiation, wellbeing/cultural notes and collapsed model answers.
- `assets/site.css`, `assets/app.js`: shared layout and student interactions. No tracking, storage, forms or external scripts.
- `assets/pioneers-EZ0005.jpg`: British Official Photographer, c.1916, Australian War Memorial EZ0005; catalogue states copyright expired / public domain. https://www.awm.gov.au/collection/C282983 . Not identified as Harold. No AI images.

Sound is optional user-initiated synthesis, not authenticated military calls or Harold's bugle. The final-page Last Post is an external AWM listening link, not a counterfeit sequence. Reflection has no alarm or autoplay.

Original DOCX, generated ZIP/images and previous app backup remain privately outside this repository. No curriculum-alignment or community cultural-review claim is made. Sources checked 7 November 2026, Australia/Perth.

Static site: no build step. Serve directory with any static HTTP server. GitHub Pages serves main/root. Keyboard navigation, mobile layout and print styles included. No browser automation used in development.
