# My Granddad was a Bugler

Six-page Year 3 remembrance story by Robin McKean (© 2026), about Harold Philip Josias Truasheim. Published at the author's request from his supplied story and HTML app.

Family narrative is preserved as supplied; no independent historical verification is claimed. Generated illustrations have been excluded. The original DOCX and generated archive are not published.

Sound buttons use user-initiated Web Audio synthesis, explicitly illustrative rather than authenticated military calls. The unverified generated Last Post sequence was removed; the final page links to the Australian War Memorial listening resource instead.

Static, self-contained HTML/CSS/JavaScript. No analytics, remote scripts, forms, stored personal data or build dependencies. No separate teacher edition.
